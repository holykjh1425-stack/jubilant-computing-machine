수정 1회는 합의한 범위 안의 문구·이미지·색상·배치 피드백을 한 번에 모아 반영하는 묶음으로 정의하는 안이다. 신규 페이지·기능·연동·디자인 방향 변경은 포함 수정 횟수와 무관하게 별도 견적·동의를 거친다. 제작자의 구현 오류 보완은 신규 기능 요청과 구분하고 조건·기간을 계약 전 별도 확정한다. AI 자동 수정은 서버가 계약 버전·남은 횟수·비용 잔액·승인을 확인해야 하며 이 매뉴얼만으로 실행 권한이 생기지 않는다.

### 제작 원가 시나리오

노동 원가 **20,000원/시간**, 위 AI 예산 상한 전액 사용, 직접원가의 **15% 예비비**, 호스팅·도메인·라이선스·결제 수수료 0원이라는 계산 가정이다. 0원 실비는 무료라는 뜻이 아니라 별도 입력 전 제외했다는 뜻이다. 실제 노동시간·공급자 요금·모델·환율·청구내역은 미측정이며 현재 유료 호출은 없다.

| 상품 | 노동+AI+예비비 계획원가 | 비교용 판매 제안가 | VAT 미확정 상태의 이익 판정 |
|---|---:|---:|---|
| 랜딩 스타터 | 74,750~120,750원 | 150,000원 | 계산 보류 |
| 비즈니스 | 172,500~287,500원 | 350,000원 | 계산 보류 |
| 비즈니스 플러스 | 345,000~529,000원 | 650,000원 | 계산 보류 |
| AI 상담형 | 540,500~862,500원 | 900,000원부터 | 계산 보류 |

민감도 예: 랜딩을 5시간, 시간원가 30,000원, AI 5,000원으로 가정하면 계획원가는 178,250원으로 150,000원 제안가보다 높다. AI 상담형의 고시간 가정 원가 862,500원에서 판매가 900,000원이 VAT 포함이라는 가정이면 공급가액 약 818,182원보다 원가가 높다. **실제 세금 판정이 아니라 손실 위험을 확인하는 가정 계산**이다. 광고·판매수수료·사후지원·사무비·소득/법인세 등을 포함하지 않아 차액을 순이익으로 부르지 않는다.

`pricing/catalog.mjs`는 VAT가 미정이면 공급가액·기여액을 null로 반환한다. 미확정 세금을 자동으로 붙이거나 제외하지 않는다. 이미 승인된 기존 자동화 상품에 이 홈페이지 가정을 덮어쓰지 않는다.

### 월 관리 운영시간·계약 조건 보완

| 관리 상품 | 고객 수정 한도 | 점검·보고 시간 가정 | 합산 월 노동 가정 | 별도 확인 |
|---|---|---:|---:|---|
| 셀프 | 유상 관리 없음 | 0분 | 0분 | 유상 점검·복원·변경은 포함하지 않음 |
| 안심 점검 | 1건·15분 | 30분 | 45분 | 실제 점검 체크리스트·보고 형식 |
| 표준 관리 | 3건·60분 | 45분 | 105분 | 백업 상태 확인과 복원 실행을 구분 |
| 비즈니스 관리 | 6건·120분 | 60분 | 180분 | 장애 1차 분석 이후 복구 작업 범위 |
| AI·고급 운영 | 계약 시 지정 | 계약 시 지정 | 개별 합의 | AI 비용 상한·대화/토큰/실행 수·수정 범위. 예제 240분을 기본 제공시간으로 약속하지 않음 |

- 수정 건수와 합산 시간 **두 조건 중 먼저 도달한 한도**를 적용하는 안이다. 점검·보고 시간은 내부 원가 가정이며 고객 수정 시간을 차감하는 근거로 자동 사용하지 않는다.
- 월 관리비는 선택이다. 미선택 고객에게 자동 구독이나 청구를 생성하지 않는다. 고객 자체 호스팅·도메인은 중복 청구하지 않는다.
- 미사용 수정을 다음 달로 이월하지 않는 안, 자료 요청·고객 승인 대기 처리, 영업시간과 응답 목표는 계약 전에 확정한다. 현 시점에 24시간 대응·응답 SLA·복구시간 보장은 없다.
- 관리 해지 시점·정산·환불·자료 인계·접근권한 회수·보관/삭제 기간은 미확정이다. 고객 데이터 자동 삭제·키 이전·계정 변경을 이 문서로 실행하지 않는다.
- 실제 요금과 수행내역을 월별 대조한 후 보고한다. 점검 실패·보안 문제는 기록하고 미검증 상태를 정상으로 표시하지 않는다.

### 월 운영비 시나리오와 현재 지출 구분

기존 인프라 실제 청구서는 이번 작업에서 조회하지 않았으므로 총 고정비는 미확인이다. 새 서버·구독·유료 AI 호출을 만들지 않아 **이번 개발의 추가 유료 지출은 0원**이다. 이 값은 기존 Supabase·도메인 등 기존 청구액이 0원이라는 뜻이 아니다.

가정: 공유 인프라 30,000원/월(실제 견적 아님), 시간원가 20,000원, 예비비 15%, 안심 3명·표준 4명·비즈니스 2명·고급 1명 총 10명. 고급 1명만 AI 월 한도 20,000원, 노동 240분을 가정하고 나머지는 위 시간을 사용한다.

마지막 매출 숫자는 미승인 제안가의 합계이며 실제 계약·매출·청구가 아니다. 세금·영업·추가 지원비 등 누락 비용이 있어 단순 차액을 수익 보장으로 사용하지 않는다. 모델 단가·환율·토큰 예측은 선택 모델과 승인된 계정의 견적 확인 전 고정하지 않고 고객별 한도로 별도 입력한다.

### 내부 배치·검증 상태

- 내부 카탈로그/원가식: `candidates/customer-platform-20261112/pricing/catalog.mjs`.
- 합성 시나리오/가정: `pricing/scenarios.mjs`, `pricing/scenarios.json`.
- 공식/판매자 원문 확인: `pricing/sources.json`.
- 검증: `pricing/pricing.test.mjs` 6개 PASS. 승인되지 않은 가격의 고객 출력 차단, 기존 10만원 상품 보존, VAT 미정 시 마진 계산 보류, 원가 합계·고정비 1회 반영, 비정상 입력 차단.
- `getCustomerPricing()`는 호출자가 administratorApproved 같은 값을 보내도 미승인 가격을 반환하지 않는다. 운영 고객 번들에는 내부 제안 카탈로그를 포함하지 않고, 승인된 가격 버전을 서버가 제공하도록 별도 적용해야 한다. 클라이언트의 숨김 처리만으로 내부 가격을 보호했다고 판정하지 않는다.
- 고객 공개 가격·자동 청구·실제 API 호출·운영 배포: **미실행 / NO-GO 유지**. 가격 승인·VAT·신규 홈페이지 착수금·계약 조건·실측 노동량·실제 월 청구·작업 수행 능력 검토 후에만 공개 전환한다.
