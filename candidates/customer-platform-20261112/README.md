기준일: 2026-11-12 KST · 담당 CORE / AUTO / SENTINEL / GUARD / FIN

**개발 후보 구현 및 합성 통합 검증 PASS, 실제 운영 적용 NO-GO.** 운영 사이트·DB·고객 데이터는 변경하지 않았다. 실제 고객 인증, 실제 AI 응답·제작, 공개 배포가 완료되었다는 의미가 아니다.

## 보존과 검증 증거

최종 자동 검증은 **49 PASS / 0 FAIL**: [통합 테스트 원문](evidence/integration-tests.txt). 이전 구성요소별 로그는 해당 디렉터리에 보존했으며 최종 합산 근거는 이 통합 로그다.

- 기존 `app.js`, 주문·관리자·제작 관리·기존 미리보기·서버 제공자·기존 챗봇 자료 등 14개 파일은 시작 커밋 대비 SHA-256 일치: [보존 기준](evidence/preservation-baseline.json), [검증 코드](integration-flow.test.mjs).
- 기존 `index.html`은 상담사 CSS/module 연결과 상담 진입 버튼만 변경했다. 기존 신청·동의·접수 RPC를 유지했다. 기존 소스를 삭제하지 않았다.
- 합성 A/B 소유권, 익명·만료·타인 접근 거부, 동의 전 저장 거부, 동의 철회, 고객의 worker 사칭·상태 승격·수정/삭제 거부를 격리 PostgreSQL(PGlite)에서 실행했다.
- 계정 결합 증명은 256비트 난수, hash-only 저장, 기본 5분·최대 15분, 계정/신청/접수/목적 결합, 일회성 원자 소비+연결 후보다. 기존 개인정보·국외이전 필수 동의도 확인한다. 실제 증명·이메일·OTP는 발급하지 않았다.
- 한 프로세스 중복 요청 100개와 PGlite 30개 claim 검증은 통과했다. PGlite 단일 연결 결과이며 분산 실행·여러 세션의 경합이나 실제 Auth 보안을 입증하지 않는다.
- 브라우저: 합성 상담→동의→기존 폼→합성 접수, 입금만 확인 시 실행 차단, 별도 승인 후 v1, 동의 후 수정 v2, B 전환·만료 시 A 시안 제거를 확인했다.
- 390×844 프레임(스크롤바 제외 client 375px), 390×360 축소 높이에서 가로 넘침 없이 패널·입력 접근을 확인했다. 축소 높이는 키보드 대응 모의이며 실물 Android 키보드 검증은 미확인이다.
- 악성 시안의 script/form/image/frame/meta/base/이벤트·외부 속성을 제거했다. 최종 위험 요소 0, 위험 속성 0. iframe `sandbox=""`, referrer none, 네트워크·스크립트 차단 CSP. 동적 생성 코드 실행 검증은 하지 않았다.

이번 작업에서 운영 데이터 행 수·지문을 다시 조회하지 않았다. 운영 데이터 보존 판정은 '무변경 수행' 범위이며 과거 운영 무결성 보고를 새 실측으로 표시하지 않는다. 백업·복원·RPO/RTO·보안 종결·기존 운영 배포 NO-GO를 이 테스트로 PASS 처리하지 않는다.

## 비용과 가격 검토

신규 유료 API 호출·서버 개설·결제 **0**, 이번 개발의 추가 유료 지출 **0원**. 기존 계정 사용료와 현재 운영 청구액은 미확인이다. 기존 업무자동화 기본형 100,000원·착수금 30,000원·잔금 70,000원을 유지했다.

시급 20,000원, 예비비 15%, 상품별 AI 예산 상한을 둔 가정이며 실제 제작 시간·API 청구 실측이 아니다. 부가세 미확정으로 순매출·이익 확정은 보류했다.

선택 월 관리비 검토안은 0 / 29,000 / 59,000 / 119,000 / 199,000원부터. 고객 10명(안심3·표준4·비즈니스2·고급1), 고정 인프라 30,000원 가정에 노동·AI 한도·예비비를 포함한 월 운영 원가 시나리오는 **495,750원**, 평균 고객당 **49,575원**이다. 이는 서버 요금이나 확정 청구액이 아니다. 호스팅·도메인·AI 사용료는 별도 표시하고 공개·자동 청구하지 않는다. [상세 가정](pricing/scenarios.json), [출처](pricing/sources.json).

## 운영 적용 및 롤백

운영 적용 전에 위 NO-GO를 해소하고 변경 파일·SQL·정책·실측 비용 상한·배포 대상을 제시하여 별도 승인을 받아야 한다. 이번 작업은 main 병합, 운영 DB 마이그레이션, 실제 고객 통지, 유료 실행, GitHub Actions 수동 실행, Sites/홈페이지 배포를 하지 않았다.

코드 롤백은 이 후보의 index 연결 변경을 되돌리고 이전 승인된 사이트 버전을 사용한다. 기존 신청·주문·관리자 소스와 고객 데이터는 보존한다. 향후 신규 테이블 적용 시에도 기록 삭제를 롤백 수단으로 삼지 않는다. 실제 서비스 롤백 시험은 미실행이다.

검증 화면은 `prepare-preview.py`로 생성한 로컬 QA 복사본이다. QA에서만 SOLQ 표기와 합성 접수 stub을 사용하고 원래 외부 스크립트를 제거했다. 운영 고객 데이터를 연결하지 않았으며 공개 URL을 발급하지 않았다. UI 검토용 합성 화면과 실제 운영 완료를 구분한다.
