## 실제 전송 어댑터의 제한

- CredReadW는 고정 대상 SOLQ-TEST-ANTHROPIC-API의 **일반 자격 증명(CRED_TYPE_GENERIC)**만 읽는다. 사용자/비밀번호를 인수로 받지 않는다. 저장 유형이 다르거나 대상이 없으면 안전 중단하며 다른 자격 증명·Vault·환경 변수·기존 운영 키를 탐색하지 않는다. 실제 PC 저장 유형/읽기 가능 여부는 아직 미검증이다.
- 반환된 OS 버퍼는 메모리에서 지운 뒤 CredFree한다. 저장된 자격 증명 자체를 쓰거나 지우는 API는 없다. 문자열/HTTP 헤더는 일시적으로 프로세스 메모리에 존재하므로 메모리 덤프·관리자·악성코드·페이징까지 완전 제거한다고 보장하지 않는다. 비밀을 출력/파일로 저장하지 않으며 HTTP 디버그 추적을 켜지 않는다.
- POST 대상은 https://api.anthropic.com/v1/messages 하나다. 모델 claude-haiku-5-5, 고정 합성 문장 Reply exactly OK., max_tokens32, thinking disabled만 보낸다. 고객 데이터·system 대화 이력·도구·배치·캐시·Sonnet fallback 없음.
- .NET HttpClient로 애플리케이션 SendAsync1회만 실행한다. SDK/자동 재시도/폴백/로그인/리다이렉트 추종/쿠키 사용이 없다. 타임아웃 설정15초이며 취소가 서버 실행·과금 취소를 보장하지 않는다. OS·네트워크·프록시의 모든 저수준 동작을 외부 exactly-once로 보장하는 것은 아니다.
- TLS1.2와 기본 인증서/호스트 검증을 사용한다. 기존 프로세스에 사용자 정의 인증서 검증 콜백이 있으면 실행을 거부한다. SSL 검증 생략·임의 호스트/IP 대체·다른 endpoint는 지원하지 않는다. 실제 사용자 PC DNS/TLS/프록시는 미검증이다.
- Workspace ID를 요청 헤더로 명시한다. 공식 문서상 Workspace 전용 키와 헤더가 다르면 거부된다. 응답 Workspace ID가 존재하고 불일치하면 중단한다. 헤더 선택에 성공했다는 사실만으로 키가 다른 Workspace에 전혀 접근할 수 없다는 권한 감사를 대신하지 않는다. 사용자 확인 외 발급 범위·정확한 만료는 사전 원격 조회하지 않았다.
- 만료 시각이 아니라 날짜만 주어졌으므로 **2026-10-29 00:00 KST부터 로컬 실행을 보수적으로 차단**한다. 제공자 측 실제 만료 시각을 확인했다는 뜻이 아니다. 자동 키 재발급·연장 없음.
