# SOLQ 상품별 고객 안내 및 내부 실행 매뉴얼 v1.0
작성: 2026-11-04 · 상태: **운영 전 검토 초안** · 소유: CORE(시스템), AUTO(자동화), GUARD(검증), SENTINEL(보안), ATLAS(총괄)
이 문서는 실제 제품 기능이 이미 완성됐다는 증거가 아니다. 운영 배포·고객 데이터 변경·유료 API·유료 광고·결제·계약은 별도 승인 없이 진행하지 않는다.

## A. 모든 상품에 적용되는 고객 안내 (고객에게 그대로 제공 가능한 문안)

### 1. 신청 전 준비
1. 공식 홈페이지 `https://solqtech.com`에 접속해 **무료 계획 신청** 메뉴가 실제로 제공되는지 확인한다. 접속한 주소가 정확한지 살핀다.
2. 해결하고 싶은 업무, 현재 사용하는 도구, 원하는 결과를 정리한다. 예: '문의 내용을 유형별로 나누어 목록으로 보고 싶습니다.'
3. 신청서에는 **이름, 회신 가능한 이메일, 서비스 종류, 작업 설명** 등 화면에서 요구하는 최소 정보만 입력한다. 실명 대신 업무 담당자 이름 사용 가능 여부는 화면 정책에 따른다.
4. **주민등록번호, 계좌·카드번호, 비밀번호, OTP, API 키, 고객 명단 원본, 의료·민감정보, 실제 거래 비밀**을 신청 설명란에 입력하지 않는다. 예시 데이터는 가명·가공한 샘플을 사용한다.
5. 개인정보 수집·이용과 국외 전송·보관 안내를 읽고 동의 여부를 선택한다. 동의하지 않으면 온라인 신청이 제한될 수 있으며, 별도 문의 경로를 확인한다.
6. 제출 후 접수번호를 안전하게 보관한다. 접수번호만으로 본인 인증이나 민감정보 열람이 가능하다고 가정하지 않는다.

### 2. 무료 6단계 계획
1. 신청 접수 → 2. 현재 업무와 문제 파악 → 3. 입력·출력 및 반복 작업 정의 → 4. 자동화 가능 범위와 제외 범위 판단 → 5. 예상 제작 순서·검증 방법 정리 → 6. 무료 계획 전달 및 고객 확인.
- 무료 계획은 제작 완료나 계약 체결을 의미하지 않는다.
- 계획의 전달 방법과 본인 확인 방식은 운영 시스템에서 별도로 검증되어야 한다.

### 3. 개별 견적과 고객 동의
1. 관리자는 고객에게 **고유한 견적번호/버전, 서비스 범위, 납품물, 제외 항목, 총액, 착수금, 잔금, 일정, 수정 횟수, 취소·환불 조건**을 안내한다.
2. 고객은 견적을 읽고 질문하거나 수정을 요청할 수 있다. 수정 시 이전 견적과 구분되는 새 버전을 제공한다.
3. 고객은 **인증된 전용 화면**에서 해당 견적 버전에 명시적으로 동의한다. 단순 페이지 열람, 신청서 개인정보 동의, 무료 계획 열람을 계약 동의로 간주하지 않는다.
4. 실제 동의 저장에는 고객 식별을 위한 안전한 인증, 견적 ID/버전, 동의 문구 버전, 동의 시각, 서버 측 감사 기록이 필요하다. 현재 서버 연결·검증 완료 여부는 미확인이다.
5. 고객은 안내된 **공식 입금 경로**만 사용한다. 채팅에서 받은 임의 계좌나 링크로 입금하지 않는다. 관리자는 은행 거래내역을 직접 대조한다.
6. **견적 동의 + 실제 입금 확인 + 관리자 별도 제작 승인** 전에는 유료 제작을 시작하지 않는다.

### 4. 제작·검증·전달
1. 관리자는 작업 범위와 허용된 테스트 데이터, 승인된 연동 권한을 확인한다.
2. 개발은 운영 데이터가 아닌 분리된 환경과 가공 샘플로 시작한다.
3. GUARD 검증: 요구사항 일치, 정상·오류 입력, 접근권한, 중복 처리, 결과 정확성, 개인정보 노출, 복구 방법.
4. 실패하면 고객에게 '검증 중/수정 중'으로 안내하고 자동 배포하지 않는다.
5. 배포 전 고객별 접근 제한, 승인된 공개 범위, 비밀키 비노출, 되돌리기 절차를 확인한다.
6. 고객에게 결과물 주소 또는 전달 방법, 사용법, 제한 사항, 지원 창구, 검수 방법을 안내한다. 고객이 실제로 열람·사용할 수 있는지 확인한다.
7. 완료 시각과 검증 증거를 기록한다. 고객에게 검증 완료를 알릴 때 실제 통과한 항목만 말한다.

### 5. 고객용 자주 묻는 질문
- **무료인가요?** 업무 분석과 6단계 계획은 무료이며 제작은 개별 견적 후 유료이다.
- **제작비는 얼마인가요?** 기본형은 100,000원부터이며, 실제 총액은 범위에 따라 견적에서 정한다. 착수금 기준은 30,000원이고 잔금은 총액에서 착수금을 뺀 금액이다.
- **10분이면 모두 완성되나요?** 표준화된 승인 완료 작업의 **제작 착수→검증→배포 목표**가 10분이다. 상담·견적·입금 확인 시간은 별도이며, 복잡한 연동·개별 개발은 추가 시간이 필요할 수 있다. 완료 시간은 보장하지 않는다.
- **개인정보를 보내야 하나요?** 상담에 꼭 필요한 정보만 입력한다. 민감한 원본 자료와 비밀키는 일반 신청서나 이메일로 보내지 않는다.
- **수정할 수 있나요?** 기본형에는 수정 1회가 포함된다. 추가 수정은 개별 견적에 따른다.

## B. 상품 1 — 기본형 규칙 기반 업무자동화 (기준 가격: 100,000원부터)
**고객 입력:** 처리하려는 반복 업무, 가공된 입력 예시 3~5개, 기대하는 분류/결과, 담당자 회신처.
**포함:** 규칙 분류 자동화 1개, 입력 1개, 결과 1개, 예시 검증, 사용 안내, 수정 1회.
**제외:** 생성형 AI, 외부 연동, 자동 발송, 결제, 추가 관리자, 월 유지관리.
**내부 실행:**
1. CORE가 접수번호·동의/견적 상태를 조회하고 실제 제작 승인 관문을 확인한다.
2. AUTO가 고객이 승인한 규칙을 버전 관리하고, 가공 샘플로 입력→분류→출력을 구성한다.
3. 정상 입력 3건, 경계 입력 2건, 잘못된 입력 2건, 반복 실행 1건으로 예상 결과를 대조한다. 고객 데이터나 다른 고객 결과가 섞이지 않아야 한다.
4. GUARD가 결과 일치·오류 안내·접근 제어·재실행 안전성·되돌리기를 확인한다.
5. 승인된 전달 방식으로 결과물과 사용 설명서를 제공하고 고객 확인을 받는다.
**10분 목표 측정:** 승인 후 제작 시작부터 고객 접근 가능한 검증된 결과 전달까지; 실패/대기 시간도 별도 기록.

## C. 상품 2 — 생성형 AI 업무자동화 (개별 견적)
**고객 입력:** 업무 목표, 가공된 예시 프롬프트/문서, 허용/금지 응답 사례, 품질 기준. 실고객 정보·비밀키는 일반 신청서로 받지 않는다.
**내부 실행:** 모델/요금·호출 제한·저장 위치·국외 이전·학습/제3자 이용 조건 확인 → 고객 및 관리자 비용 승인 → 격리 환경 구성 → 유해·부정확·환각 응답 테스트 → 비용 상한·실패 시 차단 검증 → 권한 통제된 배포.
**검증:** 예시 정답 비교, 금지 정보 출력 여부, 과도한 사용 비용 차단, API 오류 처리, 로그 비식별화, 장애 복구.
**차단:** 승인 없는 유료 API 호출 금지. 10분 내 완성은 표준화된 소규모 범위에서만 목표.

## D. 상품 3 — 외부 서비스 연동 자동화 (개별 견적)
**고객 입력:** 연동 서비스명, 필요한 이벤트/필드, 가공된 샘플, 고객이 직접 승인할 계정 권한 범위.
**보안 안내:** 비밀번호·토큰을 신청서에 입력하지 않는다. 가능하면 공급자의 공식 OAuth 승인 절차와 최소 권한을 사용한다. 승인 전 접근 권한을 요청하거나 저장하지 않는다.
**내부 실행:** 공식 API/약관·요금 확인 → 권한·데이터 흐름 설계 → 샌드박스 연결 → 성공/실패/재시도/중복 전송 테스트 → 로그 민감정보 마스킹 → 권한 회수 및 복구 테스트 → 승인 후 배포.
**검증:** 토큰 만료, 중복 웹훅, 타임아웃, 외부 장애, 권한 최소화, 데이터 보존 범위.
**차단:** 외부 서비스 계약·유료 요금·권한 변경은 별도 승인.

## E. 상품 4 — 홈페이지 제작 (개별 견적)
**고객 입력:** 상호/표시할 연락처, 서비스 소개, 로고·이미지 사용 권리, 원하는 메뉴, 공개할 정보와 비공개 정보. 실제 고객 명단이나 계정 비밀번호는 보내지 않는다.
**내부 실행:** 콘텐츠·권리 검토 → 반응형 템플릿 선택 → 공개 범위·개인정보 안내 반영 → 폼은 테스트 데이터로 검증 → 모바일/PC 접근성·링크·성능·보안 확인 → 미리보기 제공 → 고객 승인 후 배포.
**검증:** 360px 모바일/데스크톱 화면, 입력 오류, 링크, HTTPS, 개인정보 고지, 검색 노출 설정, 롤백.
**차단:** 도메인 구매·유료 호스팅·운영 배포는 별도 승인.

## F. 상품 5 — 맞춤형 신청·관리 시스템 (개별 견적)
**고객 입력:** 사용자 역할(고객/관리자), 필요한 입력 필드, 상태 흐름, 보고서, 가공된 업무 사례.
**내부 실행:** 데이터 최소화·역할 권한표 → 스키마/원자적 저장 설계 → 테스트 환경 → 역할별 접근·중복 요청·충돌·감사 로그 테스트 → 백업/복원 확인 → 관리자 검수 → 승인된 배포.
**검증:** 타인 정보 조회 차단, RLS/서버 권한, 관리자 인증, 원자적 저장, 오류·재시도, 백업·격리 복원, 고객 데이터 보존.
**차단:** 현재 SOLQ 운영 자체의 필수 검증 관문(GUARD NO-GO)을 우회하지 않는다.

## G. 상품 6 — 월 유지관리 (선택형, 개별 견적)
**고객 입력:** 유지관리 대상, 허용된 점검 시간, 담당자, 장애 연락 방법, 변경 승인자.
**내부 실행:** 대상 자산 목록과 범위 확정 → 상태 모니터링·장애 접수 → 변경 전 백업 및 영향 확인 → 격리 수정·회귀 검증 → 승인 후 적용 → 월간 이력 보고.
**검증:** 모니터링 경보, 접근권한, 백업 성공 여부, 복구 연습, 변경 이력, 장애 대응.
**차단:** 유지관리 계약에 없는 기능 개발·추가 비용·자동 결제 금지.

## H. 고객에게 보여줄 상태 표시 기준
`접수 완료` → `무료 계획 검토 중` → `무료 계획 전달` → `개별 견적 안내` → `고객 동의 확인` → `입금 확인 대기` → `관리자 제작 승인 대기` → `제작 중` → `검증 중` → `전달 완료`.
- 각 상태는 서버의 실제 증거가 있을 때만 표시한다. 예시 화면의 체크박스만으로 전환하지 않는다.
- 지연·실패는 숨기지 않고 '추가 확인 필요'와 문의 방법을 안내한다.
- 고객별 결과물은 인증된 전용 접근만 허용한다. 공개 저장소에 고객 데이터·견적 원본·토큰·동의 기록을 저장하지 않는다.

## I. 내부 최종 출고 체크리스트 (GUARD)
- [ ] 정확한 고객/접수번호 및 승인된 작업 범위 확인
- [ ] 견적 버전별 고객의 명시적 동의 증거 확인
- [ ] 은행 원본 거래내역에 근거한 수동 입금 확인
- [ ] 관리자 별도 제작 승인 확인
- [ ] 정상·경계·오류·중복·권한 테스트 PASS
- [ ] 개인정보·비밀키 비노출 확인
- [ ] 백업·복구 및 배포 롤백 요건 충족
- [ ] 고객별 안전한 결과 전달 및 사용 안내
- [ ] 실제 제작 시작·검증 완료·배포 완료 시각 기록
- [ ] 고객 검수/인수 및 지원 안내

## J. 실제 운영 연결 전 남은 필수 개발
1. CORE: 기존 SOLQ 사이트 및 Supabase의 실제 고객별 상태 조회·전달 UI 연결. 공개 화면과 GitHub 기본 브랜치 차이 검증.
2. AUTO: 무료 계획 생성 승인과 견적 버전·동의 기록·입금 확인·별도 제작 승인의 서버 상태 기계 통합.
3. SENTINEL: 고객 인증·서버 권한·토큰 수명·개인정보 최소화 및 국외 이전 통제 점검.
