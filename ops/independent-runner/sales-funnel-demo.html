무료 6단계 계획 → 개별 견적 → 고객 동의

이 페이지는 격리 시안입니다. 실제 신청·견적 발송·동의 저장·결제·제작 승인은 수행하지 않습니다. 고객 개인정보를 입력하지 마세요.

1. 무료 6단계 업무 계획

접수번호를 확인한 관리자가 무료 계획을 승인·생성하고 고객에게 전달한 뒤에만 다음 단계로 진행합니다.

  1. 요청 내용 확인
  2. 현재 업무 흐름 분석
  3. 반복 업무 분류
  4. 자동화 범위 제안
  5. 예상 작업 단계·제외 범위 정리
  6. 검토용 계획 안내

2. 개별 견적

기본형 제작비 100,000원부터, 착수금 30,000원. 아래는 기본형의 설명용 예시이며 실제 견적이 아닙니다.

기본형 예시: 규칙 기반 분류 자동화 1개, 입력 1개, 결과 1개, 예시 검증, 사용 안내, 수정 1회.

생성형 AI, 외부 연동, 자동 발송, 결제, 추가 관리자, 월 유지관리는 기본형에서 제외됩니다. 최종 총액·일정·범위는 개별 견적에서 확정합니다.

3. 고객 동의

고객은 실제 견적서의 총액, 착수금, 잔금, 작업 범위, 납기 및 취소·환불 조건을 확인한 후 동의해야 합니다.

실제 고객 동의는 인증된 고객에게 견적 버전·시각·증거를 서버에 안전하게 저장하는 기능이 별도로 필요합니다.

시연 완료

화면 흐름만 확인했습니다. 고객 동의가 접수되거나 계약이 성립한 것은 아닙니다. 실제 운영은 서버의 동의 저장과 관리자 검증을 통과해야 합니다.

입금 확인과 실제 제작 승인은 별도의 관리자 단계이며, 이 시안에서 실행할 수 없습니다.
