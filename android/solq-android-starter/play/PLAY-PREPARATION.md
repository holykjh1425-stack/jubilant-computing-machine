# SOLQ Google Play 내부 테스트 준비 초안

작성일: 2026-11-07 KST. Console 제출·게시·가격 변경은 실행하지 않았습니다.

## 스토어 문안

앱 이름: SOLQ

짧은 설명: 반복 업무 자동화 상담과 무료 6단계 계획 안내를 SOLQ에서 확인하세요.

상세 설명 초안:

반복되는 문의 분류, 자료 정리, 보고서 작성 등 업무 자동화가 필요한 내용을 SOLQ에 상담할 수 있습니다.

앱에서 SOLQ 홈페이지와 상담 신청 화면, 서비스 안내, 개인정보처리방침을 열 수 있습니다. 홈 이동, 새로고침, 앱 내 뒤로 가기와 연결 오류 시 다시 시도 기능을 제공합니다. 인터넷 연결이 필요합니다.

무료 6단계 계획은 0원입니다. 유료 제작은 개별 견적과 고객 동의, 착수금 수동 입금 확인, 별도 관리자 제작 승인 후 진행합니다. 기본형 제작비는 100,000원부터이며 기본형 착수금은 30,000원입니다. 맞춤형 제작과 선택형 유지관리는 별도 계약 조건을 따릅니다.

이 앱의 최종 실행 검증 및 Google Play 제출은 아직 완료되지 않았습니다. 이 개발상태 문장은 검증 완료 후 실제 스토어 문안과 구분하여 관리합니다. 제출 전 실제 앱 기능·요금·사업자 확인을 다시 수행합니다.

## 데이터 보안 신고 초안 — 확정 제출 금지

이 앱은 SOLQ 사이트를 제어된 WebView로 엽니다. 네이티브 분석 SDK가 없다는 사실만으로 수집 없음을 선택하면 안 됩니다. 사이트의 실제 처리와 수탁업체 계약을 운영자가 확인해야 합니다.

|데이터 후보|목적·처리 후보|제출 전 확인|
|---|---|---|
|이름·이메일·연락처|상담 접수·회신|현재 폼의 실제 필수/선택 항목, 보유기간, 삭제 절차|
|신청·문의 본문, 접수번호·동의 기록|서비스 상담·견적·처리 상태 확인|민감정보 입력 제한, 보관·삭제 기준|
|사용자가 선택한 첨부파일|상담 자료 전달|실제 업로드 경로, 저장 위치·보유기간·유형|
|쿠키·세션 및 요청/보안 로그|로그인·서비스 기능·보안|사용자/기기 식별 가능성, IP 처리, 운영자·호스팅 제공자 처리|

수집·공유·일시처리·암호화·삭제 요청의 응답은 미확정입니다. 수탁처리와 제3자 공유는 Play 정의로 구분하고 확인되지 않은 '공유 없음', '모두 암호화', '자동 삭제'를 선언하지 않습니다. WebView 공개 웹 탐색의 예외를 자체 서비스 처리에 그대로 적용하지 않습니다.

내부 테스트 트랙만 활성인 앱은 Data safety 표시 예외가 있으나 개인정보·보안 의무와 향후 공개/비공개 트랙 준비가 면제되는 것은 아닙니다.

개인정보 URL: https://solqtech.com/privacy.html . 이번 Work HTTP 요청은 403으로 차단되어 실제 페이지 내용·앱 처리와의 일치 여부를 재확인하지 못했습니다. 기존 데스크톱 확인 증거와 이번 접근 제한을 구분합니다.

## 앱 콘텐츠 초안

- 앱 유형: 업무 생산성·서비스 상담 후보. 실제 제공 기능 기준으로 Owner 확정.
- 광고: 현재 소스에 광고 SDK 없음. WebView 사이트/외부 SDK 실제 광고 여부는 운영자 확인 후 신고.
- 대상 연령: 성인 사업자·업무 담당자를 대상으로 하는 18세 이상 후보. 앱이 다루는 실제 콘텐츠와 사업 대상에 대해 Owner가 확정해야 합니다. 어린이 대상이라고 임의 선택하지 않습니다.
- 콘텐츠 등급: IARC 설문 미작성. 앱을 실행하고 실제 콘텐츠 확인 후 응답; 특정 등급을 보장하지 않습니다.
- 앱 접근: 공개 상담 기능과 관리자 제한 기능 구분. 심사 접근이 필요하면 전용 최소권한 테스트 계정을 별도 승인으로 준비하며 운영 관리자 인증정보를 제출하지 않습니다.
- 디지털 상품·구독 결제 정책: 웹 결제의 허용 여부와 서비스 유형 검토 미완료. 이번 앱에서 결제 실행·우회 경로 추가 없음.
- 개인 개발자 인증, 판매자 선언, 패키지 기존 등록, versionCode 업로드 이력은 Console에서 별도 확인 필요. 이번에는 Console 접근/변경하지 않았습니다.

## 서명 및 내부 테스트 체크리스트

1. 기존 업로드 키/Play App Signing 이력은 Owner가 보호 저장소에서 확인합니다. 미발견을 신규 키 생성 승인으로 간주하지 않습니다.
2. 이미 등록한 앱이면 기존 업로드 키를 사용하거나 공식 키 재설정 절차를 별도 승인받습니다. 새 앱이어도 업로드 키 생성·보관·암호화 백업 책임자를 승인받기 전 새 키를 만들지 않습니다.
3. 프로젝트의 SOLQ_UPLOAD_* 값은 안전한 로컬 프로세스로만 공급합니다. 키·비밀번호·명령 인자·로그·GitHub·ZIP에 비밀값을 넣지 않습니다. 디버그키를 업로드키로 대체하지 않습니다.
4. 릴리스 AAB에 업로드 서명 적용 후 인증서 지문, 구조, 패키지, API, versionCode를 확인합니다. 서명 없는 AAB는 제출하지 않습니다.
5. 실기기/에뮬레이터의 Android 15·16에서 탐색·큰 글꼴·TalkBack·회전·파일 선택/취소·오프라인 복구·개인정보 링크를 검증합니다. 운영 신청은 제출하지 않고 격리 접수 대상이 없으면 보류합니다.
6. Owner 별도 승인 후에만 Console > Test and release > Testing > Internal testing에 제출합니다. 테스트 대상 최대 100명, 명단/초대 공개 범위는 Owner 확정. 업로드·테스터 초대·내부 릴리스도 현재 미승인입니다.
7. 내부 테스트는 공개 출시가 아닙니다. 개인 계정에 적용되는 별도 비공개 테스트 및 프로덕션 접근 요건은 계정 상태 확인 후 별도 처리합니다.
